Dnevnik Kalendar

Dnevnik Kalendar is a personal, non-commercial program that runs on its owner's own computer. It keeps a private to-do list and synchronizes it with a single Google Calendar named "Дела" that the program creates itself. It is not offered to the public.

Privacy Policy

What data is accessed. The program requests only the Google Calendar scope calendar.app.created. With it, the program can create one secondary calendar and read, create, change and delete events in that calendar only. It cannot see the user's other calendars or events.

How data is used. Events in that calendar are used only to keep them in sync with the to-do list on the owner's computer.

Storage and sharing. All data is stored locally on the owner's computer. No data is sent to any server other than Google's own API, and no data is sold, shared or transferred to third parties. No analytics or advertising is used.

Revoking access. Access can be revoked at any time at myaccount.google.com/permissions.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
